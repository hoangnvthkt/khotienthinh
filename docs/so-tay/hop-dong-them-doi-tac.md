**Khi nào:** có NCC, chủ đầu tư, nhà thầu hay tổ đội mới cần dùng trong hợp đồng, đơn mua, thanh toán.
**Các bước:**
1. Hợp đồng → **Đối tác**; gõ tên / MST vào ô "Tìm mã, tên, MST, liên hệ..." để chắc chưa có.
2. Bấm **Thêm đối tác**.
3. Nhập **Tên khách hàng** (bắt buộc), tích **Phân loại**: Chủ đầu tư / Nhà thầu / Nhà cung cấp / Tổ đội; điền **Mã số thuế**, địa chỉ, liên hệ, **Ngân hàng**, **Tài khoản**.
4. Bấm **Lưu đối tác**. Mã để trống thì tự sinh.
5. Nhiều đối tác: bấm **Mẫu** tải file Excel → điền → **Nhập mới** (hoặc **Cập nhật** để sửa hàng loạt).
**Không làm được?**
- Không thấy **Thêm đối tác** → nhờ Admin cấp Đối tác · Quản trị.
- Đối tác không hiện khi chọn ở HĐ NCC / HĐ nhận thầu → chưa tích đúng phân loại hoặc đang **Ngưng dùng**.
- Đề nghị chi báo NCC chưa có số tài khoản → sửa đối tác, điền **Ngân hàng**, **Tài khoản**.
**Lưu ý:**
- Thùng rác = ngưng sử dụng (giữ lịch sử), không xóa hẳn. Nên ghi MST để hóa đơn XML / AI tự tìm đúng NCC; tránh tạo trùng MST.
