**Khi nào:** đối chiếu tình trạng tài sản thực tế với hệ thống (định kỳ, bàn giao, cuối năm).
**Các bước:**
1. **Tài sản** → **Kiểm kê TS** → tab **Kiểm kê**.
2. Tìm tài sản theo tên / mã hoặc lọc theo loại.
3. Từng tài sản bấm tình trạng thực tế: **Tốt**, **Hư hỏng**, **Mất**, **Sai vị trí** (bấm lại để bỏ chọn); **Sai vị trí** thì ghi vị trí thực tế; thêm ghi chú nếu cần.
4. Bấm **Hoàn tất** để lưu phiên kiểm kê.
5. Xem lại hoặc **Xuất Excel** ở tab **Lịch sử**.
**Không làm được?**
- Chỉ thấy tab **Lịch sử** → thiếu quyền "Kiểm kê tài sản · Kiểm kê" → nhờ Admin cấp (Cài đặt → Người dùng → Sửa → Tài sản).
- **Hoàn tất** mờ → chưa bấm tình trạng cho tài sản nào.
- Báo "Chưa lưu được phiên kiểm kê" → dữ liệu vẫn trên màn, bấm **Hoàn tất** lại.
**Lưu ý:**
- Chỉ tài sản đã bấm tình trạng mới vào phiên kiểm kê.
