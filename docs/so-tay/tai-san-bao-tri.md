**Khi nào:** tài sản hỏng cần sửa, đến kỳ bảo trì, hoặc gửi bảo hành.
**Các bước:**
1. **Tài sản** → **Bảo trì / Sửa chữa** → **Tạo mới**.
2. Chọn **Tài sản**, **Loại** (Sửa chữa / Bảo trì định kỳ / Kiểm tra / Bảo hành), **Trạng thái**, ghi **Mô tả**.
3. Ghi ngày, **Chi phí dự kiến (báo giá)**, **Đơn vị sửa chữa / Nhà cung cấp**, **Số hoá đơn**; kéo thả hóa đơn / chứng từ vào ô đính kèm.
4. Bấm **Lưu bản ghi**.
5. Sửa xong: bấm biểu tượng **Đánh dấu hoàn thành** trên dòng.
**Không làm được?**
- **Lưu bản ghi** mờ → chưa chọn tài sản hoặc chưa ghi mô tả.
- Tạo với trạng thái **Hoàn thành**, hoặc bấm **Đánh dấu hoàn thành**, báo xong nhưng tải lại không thấy đổi → hiện chỉ Admin cập nhật được bản ghi bảo trì → nhờ Admin.
- Nhân viên muốn báo hỏng → chưa có nút báo hỏng riêng → báo người phụ trách tài sản tạo bản ghi **Sửa chữa**.
**Lưu ý:**
- Nhiều bản ghi một lúc: **Import Excel**.
- Chi phí sửa chữa cộng dồn vào hồ sơ tài sản (**Chi phí BT/SC**).
