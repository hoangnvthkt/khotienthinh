**Khi nào:** ký hợp đồng mua bán / cung ứng / dịch vụ với NCC, cần lưu vào Vioo.
**Các bước:**
1. Hợp đồng → **HĐ Nhà cung cấp** → **Thêm hợp đồng**.
2. Có file: bấm **Đọc hợp đồng (AI)**, chọn ảnh chụp hoặc PDF → AI điền mã, tên, NCC (theo MST), giá trị, ngày ký / hiệu lực / hết hạn, điều khoản thanh toán vào ô trống. Kiểm lại.
3. Điền thêm: **Mã hợp đồng**, **Tên hợp đồng**, **Dự án**, **Nhà cung cấp**, **Trạng thái**; đính file hợp đồng.
4. Bấm **Lưu hợp đồng**.
5. Bấm **Xem chi tiết** (biểu tượng mắt): tab **Đơn giá** → **Thêm đơn giá**; tab **Tài liệu** tải thêm file.
**Không làm được?**
- Không thấy **Thêm hợp đồng**, có dòng "Bạn đang có quyền xem…" → nhờ Admin cấp Hợp đồng nhà cung cấp · Quản trị.
- Báo "Vui lòng chọn dự án liên kết" / thiếu mã, tên → điền đủ ô có dấu *.
- Không thấy NCC trong danh sách → đối tác chưa tích phân loại Nhà cung cấp hoặc đang ngừng dùng; sửa ở **Đối tác**.
- AI báo chưa cấu hình / hết lượt → điền tay như thường.
**Lưu ý:**
- Xóa (thùng rác) là xóa hẳn; HĐ kết thúc nên đổi **Trạng thái**. HĐ nguyên tắc gọi hàng theo tháng: Mua hàng cũng khai được ở tab **Hợp đồng nguyên tắc** → **Khai HĐ mới**.
